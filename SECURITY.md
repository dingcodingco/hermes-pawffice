# Security

Pawffice can send tasks to your Hermes bots, and a Hermes bot can run terminal commands. Treat the API key like a password.

- Pawffice listens on `127.0.0.1` only. Do not expose it to the internet or your LAN.
- Keep keys in `.env`, which is git-ignored. Never paste them into issues or screenshots.

## Reporting a vulnerability

Please use GitHub's private reporting (Security → Report a vulnerability) instead of a public issue.
